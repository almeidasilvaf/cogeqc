# Intepro annotation for Arabidopsis thaliana's genes

The annotation data were retrieved from PLAZA Dicots 5.0.

## Usage

``` r
data(interpro_ath)
```

## Format

A 2-column data frame:

- Gene:

  Character of gene IDs.

- Annotation:

  Character of Interpro domains.

## References

Van Bel, M., Silvestri, F., Weitz, E. M., Kreft, L., Botzki, A.,
Coppens, F., & Vandepoele, K. (2021). PLAZA 5.0: extending the scope and
power of comparative and functional genomics in plants. Nucleic acids
research.

## Examples

